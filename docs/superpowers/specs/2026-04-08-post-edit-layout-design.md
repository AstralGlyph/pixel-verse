# 编辑文章页面布局重构设计

> 日期: 2026-04-08
> 状态: 待实现

## 目标

重新优化编辑文章页面的组件样式和布局，解决以下问题：
- 组件位置不合理
- 编辑器宽度受限
- 样式不够美观
- 操作流程不顺畅

## 架构决策

采用 **方案 C：抽屉设置 + 大纲压缩** 布局

### 布局结构

```
┌──────────────────────────────────────────────────────────────────┐
│  ← 编辑文章                    [⚙ 设置]    保存  发布  👁 预览    │
├────────────────────────────────────────┬─────────────────────────┤
│  标题输入 (max-w-4xl)                  │   文章大纲 (sticky)      │
│  URL 别名 + 摘要                       │   w-[280px]              │
│  ┌──────────────────────────────────┐  │                         │
│  │   富文本编辑器 (max-w-4xl)       │  │  抽屉打开时:             │
│  │   居中                            │  │  大纲 w-[200px]         │
│  └──────────────────────────────────┘  │  抽屉 w-[320px]          │
│  封面图选择                             │  过渡动画 300ms          │
└────────────────────────────────────────┴─────────────────────────┘
```

### 组件层级

- `PostEditPage` — 页面容器
  - Header 区域（返回、标题、设置按钮、保存、发布、预览）
  - 消息提示区
  - 主内容区（flex）
    - 左侧主内容（flex-1, space-y-4）
      - 标题输入
      - URL 别名 + 摘要（grid 2列）
      - 编辑器容器（max-w-4xl, mx-auto）
      - 封面图选择
    - 右侧面板（transition-all, 宽度动态变化）
      - 文章大纲（始终显示）
      - 设置抽屉（条件渲染，slide-in 动画）

### 设置抽屉

**触发方式**：
- Header 中的 `[⚙ 设置]` 按钮
- 快捷键 `Ctrl/Cmd + ,`（可选）

**抽屉内容**（从上到下，可滚动）：
1. **发布设置**：状态下拉、定时发布
2. **分类和标签**：分类下拉、标签选择器
3. **SEO 设置**：SEO 标题、描述、关键词
4. **封面图**：封面图选择器

**交互**：
- 右侧滑入，带半透明遮罩
- 点击遮罩或 `×` 关闭
- ESC 键关闭
- 抽屉打开时，大纲从 280px 平滑压缩到 200px

### 编辑器宽度

- `max-w-4xl` (896px)
- `mx-auto` 居中
- 小屏幕下自然响应（100% 宽度）

### 响应式行为

| 断点 | 布局 |
|------|------|
| `< md` | 单列，大纲折叠为可展开区域 |
| `≥ md` | 双列，右侧大纲 280px |
| `≥ lg` | 右侧面板 sticky 跟随 |
