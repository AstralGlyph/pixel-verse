# 设计文档：CMS 后台 "Paper Garden" 纸花园重设计

**日期**: 2026-04-10
**状态**: 待审批
**作者**: Claude Code
**分支**: 004-admin-cms

---

## 1. 背景与目标

### 现状问题

现有 CMS 后台采用 Glassmorphism + Bento Grid 风格，蓝色调冷色配色。虽然功能完整，但视觉风格偏向"传统 CMS"，缺乏高级感和独特性。

### 设计目标

- 打造温暖、自然、高级的视觉语言
- 营造"创作氛围"，契合博客/内容管理的产品属性
- 提升整体质感，向 Linear、Notion、Craft 等现代工具看齐
- 保持功能完整性和操作效率

### 设计灵感

Notion（自然感）、Bear（温暖纸质感）、Craft（精致细节）、Apple Design（克制优雅）

---

## 2. 设计原则

| 原则 | 说明 |
|------|------|
| **温暖** | 暖色调、柔和阴影、纸张质感，避免冷硬的科技蓝 |
| **呼吸** | 更大的间距、更宽松的排版、内容有足够的留白 |
| **有机** | 圆角更大、边框更柔和、动效更自然（纸张翻动感） |
| **克制** | 两色强调系统（橄榄绿主 + 陶土橙辅），不滥用颜色 |
| **精致** | 多层柔和阴影、微妙纹理、细腻的 Hover 反馈 |

## 3. 布局架构

### 3.1 整体结构

```
┌─────────────────────────────────────────────────────┐
│                                                      │
│   ┌─────────────────────────────────────────────┐    │
│   │  页面标题                                    │ ◂─ 顶部栏（固定）
│   │  面包屑 + 操作按钮                           │    半透明暖白底
│   └─────────────────────────────────────────────┘    虚线分隔底边
│                                                      │
│   ┌─────────────────────────────────────────┐        │
│   │                                         │        │
│   │          内容卡片区域                    │ ◂─ 主内容区
│   │          （Bento Grid 或列表）           │    暖白卡片 + 柔和阴影
│   │                                         │        │
│   └─────────────────────────────────────────┘        │
│                                                      │
│  ┃                                                    │
│  ┃  ◂ 书脊（默认4px）                                │
│  ┃     悬停展开 → 260px 浮动面板                      │
│  ┃     毛玻璃 + 圆角右侧                              │
│                                                      │
└─────────────────────────────────────────────────────┘
```

### 3.2 可收起侧边栏（核心创新）

| 状态 | 宽度 | 触发方式 | 视觉描述 |
|------|------|----------|----------|
| 收起 | 4px | 默认状态 | 左侧边缘橄榄绿渐变线，鼠标悬停出现箭头提示 |
| 展开 | 260px | 悬停/点击 | 右侧圆角 + 毛玻璃 + 多层阴影，像从书页中滑出 |
| 固定 | 260px | 点击图钉图标 | 固定在左侧，保持有机风格但变为传统侧边栏 |

**交互细节**：
- 展开动画：`ease-float` 400ms，带弹性阻尼
- 展开时主内容区自动右移，避免遮挡
- 移动端：侧边栏变为底部抽屉式导航

### 3.3 导航项设计

每个导航项设计为"纸片"效果：

| 状态 | 样式 |
|------|------|
| 默认 | 无背景，深炭灰文字，Lucide 图标 stroke-width: 2 |
| Hover | 暖米色背景 `oklch(95% 0.012 85)` + 左侧 2px 橄榄绿边框 |
| 活跃 | 纸张白底 + 左侧 3px 橄榄绿边框 + 柔和阴影（像一张被抽出的卡片） |

### 3.4 顶部栏

- 背景：半透明暖白 `glass-bg` 暖色调版本
- 左侧：面包屑导航（首页 / 文章管理 / 编辑）
- 右侧：搜索框（大圆角、虚线边框）+ 用户头像（圆形 + 橄榄绿 2px 边框）
- 底边：1px 虚线分隔

### 3.5 内容区

- Bento Grid 卡片风格保留并升级
- 卡片圆角：20px
- 卡片背景：极暖白 `oklch(99.5% 0.003 85)`
- 卡片间距：gap-6（24px），比现有 gap-4（16px）更大
- 全宽卡片：统计卡片保留 Bento Grid 布局，列表改为全宽

## 5. 组件规范

### 5.1 圆角系统

```css
--radius-sm: 8px    # 小标签、徽章、按钮
--radius-md: 14px   # 按钮、输入框、小卡片
--radius-lg: 20px   # 卡片、面板
--radius-xl: 28px   # 大面板、对话框、侧边栏
```

### 5.2 动效系统

```css
--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);  # 弹性效果
--ease-paper: cubic-bezier(0.25, 0.1, 0.25, 1.0);  # 纸张翻动感
--ease-float: cubic-bezier(0.4, 0, 0.2, 1);        # 平滑浮动

--duration-instant: 100ms  # 微小反馈
--duration-fast: 200ms     # 常规交互
--duration-normal: 300ms   # 页面级变换
--duration-slow: 500ms     # 大幅展开/收起
```

#### 关键动效映射

| 交互 | 动效 | 时长 | Easing |
|------|------|------|--------|
| 侧边栏展开/收起 | float 滑入滑出 | 400ms | `ease-float` |
| 卡片 Hover | 阴影加深 + 2px 上移 | 200ms | `ease-spring` |
| 按钮点击 | 1px 下移 + 阴影减小 | 100ms | `ease-smooth` |
| 列表项进入 | 从下方滑入 + 淡入 | 300ms | `ease-paper` |
| 标签切换 | 背景渐变 + 左边框滑入 | 200ms | `ease-smooth` |

### 5.3 边框风格

- **默认卡片**：1px 实线，`--color-border-primary`
- **活跃/聚焦**：2px `--color-border-accent` + 外发光 `0 0 0 3px --color-accent-primary/10`
- **分隔线**：1px 虚线 `border-style: dashed`
- **输入框**：2px 边框，聚焦时变为橄榄绿

### 5.4 图标

- 使用 Lucide React 图标库
- stroke-width 统一从 1.5 改为 2.0
- 活跃状态图标填充橄榄绿色
- 侧边栏图标：默认描边样式，hover 时变填充样式

### 5.5 排版

| 层级 | 字重 | 字号范围 | 颜色 |
|------|------|----------|------|
| 页面标题 | 600 | 24-28px | `--color-text-primary` |
| 区块标题 | 600 | 16-18px | `--color-text-primary` |
| 卡片标题 | 500 | 14-16px | `--color-text-primary` |
| 正文 | 400 | 14px | `--color-text-primary` |
| 辅助文字 | 400 | 12-13px | `--color-text-secondary` |
| 时间戳 | 400 | 11-12px | `--color-text-tertiary` |
| 数字/统计 | 700 | 32-40px | 强调色 |

### 5.6 Glassmorphism 处理

| 特性 | 处理 |
|------|------|
| `glass-card` 类 | 移除 `backdrop-filter: blur` |
| 毛玻璃背景 | 替换为实色 `--color-card-bg` |
| 圆角 | 保留并放大至 20px |
| 阴影 | 从锐利玻璃阴影改为多层柔和纸张阴影 |
| 顶部栏 | 保留毛玻璃效果（需要内容透明感） |

## 8. 验收标准

### Given-When-Then 格式

```gherkin
Feature: CMS 后台 Paper Garden 重设计

  Scenario: 默认亮色主题加载
    Given 用户打开 CMS 后台首页
    When 页面加载完成
    Then 背景为暖白色（非冷白）
    And 侧边栏默认收起显示为 4px 橄榄绿渐变线

  Scenario: 侧边栏悬停展开
    Given 用户鼠标悬停在左侧书脊区域

  Scenario: 导航项活跃状态
    Given 用户点击侧边栏中的某个导航项

  Scenario: 卡片 Hover 效果
    Given 用户悬停在内容卡片上
    When Hover 状态激活
    Then 卡片上移 2px
    And 阴影从 --shadow-card 变为 --shadow-card-hover
    And 动画使用 ease-spring 200ms

  Scenario: 暗色主题切换
    Given 用户切换到暗色主题
    When 主题切换完成
    Then 背景变为深暖灰色（非深蓝黑）
    And 文字变为暖白色
    And 强调色变为亮橄榄绿
```

## 9. 设计决策记录

### ADR-001: 为什么选择暖色调替代冷色调

**决策**: 采用暖色调（hue 85-132）替代现有冷色调（hue 260）

**理由**:
1. 博客/内容管理产品的核心场景是"创作"，暖色调更能营造舒适、专注的创作氛围
2. 市场上主流创作工具（Notion、Bear、Craft）均采用暖色调或中性色调
3. 冷色调在长时间使用时更容易产生视觉疲劳

**替代方案**: 保持冷色调但降低饱和度 — 被拒绝，因为无法从根本上改变"传统 CMS"的观感

### ADR-002: 为什么移除 Glassmorphism 效果

**决策**: 移除主内容区的毛玻璃（`backdrop-filter: blur`）效果

**理由**:
1. 毛玻璃效果在大量内容区域性能开销较大
2. 纸张质感更符合"Paper Garden"的设计语言
3. 顶部栏保留毛玻璃以维持层次感

**替代方案**: 保留毛玻璃但减少模糊程度 — 被拒绝，因为不够"有机自然"

### ADR-003: 双色强调系统

**决策**: 使用橄榄绿（主）+ 陶土橙（辅）双色系统，替代现有六色系统

**理由**:
1. 减少视觉噪音，更聚焦
2. 绿色代表生长/创作（博客的核心隐喻）
3. 陶土橙作为补充强调，温暖但不刺眼
4. 更"高级"的设计往往用色更克制（参考 Apple、Linear）
