**日期**: 2026-04-08

## 概述

为 pixel-verse 项目实现完整的浏览器尺寸适配，确保前端页面和管理后台在手机、平板、笔记本、大屏显示器上都有良好的用户体验。

---

## 目标设备范围

| 设备 | 断点 | 宽度范围 |
|------|------|----------|
| 手机（竖屏） | `< sm` | `< 640px` |
| 平板 | `sm` – `md/lg` | `640px – 1024px` |
| 笔记本 | `lg` – `xl` | `1024px – 1440px` |
| 大屏显示器 | `> xl` | `> 1440px` |

使用 Tailwind CSS 默认断点：`sm: 640px`, `md: 768px`, `lg: 1024px`, `xl: 1280px`, `2xl: 1536px`

## 一、前端页面响应式设计

前端页面已有较好的响应式基础，主要工作是补充和完善。

### 1.1 Header 导航

- **手机 (`< md`)**: 使用现有汉堡菜单（已实现）
- **平板及以上 (`md+`)**: 水平导航栏，内容居中
- **搜索按钮**: `sm` 以下隐藏（已实现）

### 1.2 内容网格

- **手机**: 1 列布局（`grid-cols-1`）
- **平板**: 2 列布局（`md:grid-cols-2`）
- **笔记本/大屏**: 3 列布局（`lg:grid-cols-3`）
- **大屏内容限制**: 添加 `max-w` 限制内容区域宽度，避免过宽影响阅读

### 1.3 文章详情页 (PostLayout)

- **手机/平板**: 全屏单列，TOC 隐藏或改为可折叠面板
- **笔记本及以上 (`lg+`)**: 文章内容 + 右侧 TOC 侧边栏（已实现）
- **文章内容**: 添加 `max-w-prose` 或 `max-w-[65ch]` 限制，大屏阅读友好

### 1.4 响应式图片

- 添加 `loading="lazy"` 懒加载
- 使用 `srcset` 提供多种尺寸（可选）

## 二、管理后台响应式设计

管理后台支持平板、笔记本、大屏三种尺寸，不支持手机。

### 2.1 侧边栏行为

| 尺寸 | 默认状态 | 用户操作 | 侧边栏宽度 |
|------|----------|----------|-----------|
| 平板 (`< lg`) | 图标栏 | 悬停/点击展开浮层 | 48px（收起） |
| 笔记本 (`lg – xl`) | 完整展开 | 点击按钮切换 | 200px（展开）/ 48px（收起） |
| 大屏 (`> xl`) | 完整展开 | 点击按钮切换 | 256px（展开）/ 48px（收起） |

### 2.2 侧边栏交互细节

**展开状态**:
- 显示 Logo + 完整菜单项（图标 + 文字）
- 右上角显示收起按钮（◀）
- 当前活跃菜单项高亮

**收起状态 (48px)**:
- 仅显示图标
- 悬停图标显示 Tooltip（菜单名称）
- 顶部显示展开按钮（▶）
- 当前活跃菜单项图标高亮

### 2.3 平板特殊处理

- 默认 48px 图标栏
- 手动展开/收起按钮隐藏
- 悬停图标时弹出浮层（约 180px 宽）显示菜单项
- 点击浮层菜单项导航，点击遮罩关闭

### 2.4 状态管理

- 使用 **Zustand** 存储侧边栏折叠状态
- **localStorage 持久化**: 记住用户上次的展开/收起偏好
- **默认行为**: 平板默认收起，笔记本/大屏默认展开
- **状态字段**: `{ collapsed: boolean }`

### 2.5 动画过渡

- 侧边栏宽度变化使用 CSS `transition` 平滑过渡（`transition-all duration-200`）
- 浮层出现/消失使用淡入淡出动画
- 动画不影响内容布局流

## 四、技术实现要点

### 4.1 组件拆分

1. **`SidebarCollapsed.tsx`**: 图标栏组件（48px）
2. **`SidebarExpanded.tsx`**: 完整侧边栏组件
3. **`Sidebar.tsx`**: 组合组件，根据屏幕尺寸和折叠状态切换显示
4. **`useSidebarStore.ts`**: Zustand store，管理折叠状态
5. **`SidebarTooltip.tsx`**: 收起状态下的 Tooltip 组件

### 4.2 断点检测

- 使用 CSS media query + React 状态检测屏幕宽度
- 或使用 Tailwind 的响应式类 + `hidden`/`block` 切换
- 推荐方案：纯 CSS 响应式类，无需 JS 检测

### 4.3 数据表格横向滚动

```tsx
<div className="overflow-x-auto">
  <table className="min-w-full">
    {/* 表格内容 */}
  </table>
</div>
```

### 4.4 内容最大宽度

大屏下内容区域添加 `max-w-7xl mx-auto` 限制，避免内容过宽。

## 五、错误处理与边界情况

- **屏幕旋转/窗口调整**: CSS 响应式自动适配，无需额外处理
- **侧边栏收起后 Tooltip 被内容遮挡**: 使用 `z-index` 确保 Tooltip 在最上层
- **平板悬停浮层与主内容冲突**: 浮层使用绝对定位 + `z-index`，点击遮罩关闭
- **无鼠标设备（触屏平板）**: 点击图标而非悬停触发弹出层
